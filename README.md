# Advanced EDA & Feature Engineering

## Description

This project is completed as part of the **DecodeLabs Data Science Internship – Project 1**.

The project performs Exploratory Data Analysis (EDA) and Feature Engineering on a Marketing & Sales dataset containing **60,000 records and 23 original columns**.

The project includes data inspection, missing value treatment, outlier detection using IQR, categorical encoding, feature engineering, multicollinearity analysis, feature selection, Pandera validation, and a point-in-time/data leakage check.

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/aroojfatimay/DecodeLabs-Internship.git
```

### 2. Open the project folder

```bash
cd DecodeLabs-Internship/Project-1-Advanced-EDA
```

### 3. Install the required libraries

```bash
pip install pandas numpy matplotlib pandera jupyter
```

### 4. Open the Jupyter Notebook

```bash
jupyter notebook
```

Then open:

```text
notebooks/Project_1_EDA.ipynb
```

### Dataset

The raw dataset is located in:

```text
data/raw/marketing_sales_dataset.csv
```

The processed dataset is saved in:

```text
data/processed/marketing_sales_processed.csv
```
